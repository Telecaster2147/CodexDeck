# 仓库文件边界

## 公开内容

- 根目录：README、LICENSE、安装/卸载脚本、开发启动器、Python 构建配置与锁文件。
- `src/codexdeck/`：发行代码与运行时样式。
- `tests/`：测试与匿名 fixtures，不放真实 rollout、数据库或用户日志。
- `tools/`：可复用的测试、性能、PTY 和自动发布工具。
- `.github/`：CI、发布流程和 issue 模板。
- `docs/`：用户参考、开发规范、维护指南与版本说明。
- `assets/`：公开截图和静态资源，只使用匿名样本。

## 本地内容

个人计划、交接、设计草案、审计记录和手工发布文件放在 `.local/`，默认不提交。
仓库根目录的 AGENTS.md 为本地工具入口，继续保留并忽略；既有本地文件也受精确规则保护。
第三方 Codex 源码副本、凭据、环境、缓存、构建物、日志和测试报告保持忽略。

不要使用 `*.md` 之类规则笼统忽略文档；公开发布说明必须保持受版本控制。
`.gitignore` 不会移除已跟踪文件，也不会删除历史。变更忽略规则时运行仓库治理测试。

## 清理与提交

移动公开文档时同时更新 README 链接、测试和 sdist manifest。避免留下失效链接。
已有公开标签和 Release 默认保持不可变。清除历史要单独确认文件清单、分支/标签范围，
创建独立完整备份（例如忽略的 `.local/history-backups/`）并记录旧新提交映射，再使用精确 lease 推送；GitHub 缓存及第三方副本
也需要分别处理。普通删除提交不等于历史内容清除。
