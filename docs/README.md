# 文档目录

公开文档只记录可复用的产品行为、开发契约和维护流程，不保存个人工作记录。

| 目录 | 内容 | 面向 |
| --- | --- | --- |
| `reference/` | 状态、证据、协议、Terminal 和网络边界 | 用户与集成开发者 |
| `development/` | 架构、测试与贡献规范 | 贡献者 |
| `maintainers/` | 自动发布和发布后维护流程 | 项目维护者 |
| `releases/` | 各版本简短说明，供 Actions 创建 Release | 全部用户 |

根目录 README 负责安装与使用；技术细节放在对应目录，不在根目录堆积文档。
